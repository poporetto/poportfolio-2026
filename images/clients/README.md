# Client Logos

Place your client logo images in this directory.

## File Naming Convention
- `client-1.png` - First client logo
- `client-2.png` - Second client logo
- `client-3.png` - Third client logo
- `client-4.png` - Fourth client logo
- `client-5.png` - Fifth client logo
- `client-6.png` - Sixth client logo
- `client-7.png` - Seventh client logo
- `client-8.png` - Eighth client logo

## Image Specifications
- **Format**: PNG, SVG, or JPG
- **Recommended size**: 150x150px to 300x300px
- **Background**: Transparent (PNG) or white background
- **Aspect ratio**: Square (1:1) works best

## Notes
- If an image is missing, a placeholder will be displayed automatically
- Logos will be displayed in grayscale by default and become colored on hover
- Make sure images are optimized for web (compressed) for better performance
